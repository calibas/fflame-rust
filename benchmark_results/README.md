# Benchmark Results

This directory contains performance benchmark data for tracking regressions over time.

## Files

- **`unified_benchmarks.csv`** - Historical performance data
  - Timestamped entries for all benchmarks
  - Includes CPU (Criterion) and GPU (rendering) tests
  - Append-only for long-term tracking

- **`last_run.json`** - Cached baseline for regression detection
  - Latest benchmark run results
  - Used for comparison in next run
  - Automatically updated after each benchmark

- **`benchmark_history.csv`** - Legacy commit comparison data
  - Generated by `scripts/benchmark_commits.py`
  - **Deprecated** - use `unified_benchmarks.csv` instead

## Running Benchmarks

### Unified Benchmark Suite (Recommended)

```bash
# Full benchmark suite (CPU + GPU desktop + GPU WASM)
python scripts/run_benchmarks.py

# Quick mode (skip WASM, faster Criterion)
python scripts/run_benchmarks.py --quick
```

**What it tests:**
1. **CPU Microbenchmarks** (Criterion)
   - Affine transforms, point helpers, color blending
   - HashMap lookups, transform cloning
   - Statistical analysis with regression detection

2. **GPU Rendering** (Desktop CLI)
   - All test configs in `tests/visual/configs/`
   - PNG metadata extraction (iterations, render time, throughput)

3. **GPU Rendering** (WASM Browser) - Optional
   - Browser-based WebGPU rendering
   - Same configs as desktop for comparison

**Output:**
- Console report with color-coded results
- CSV append to `unified_benchmarks.csv`
- Baseline cache to `last_run.json`

**Regression Thresholds:**
- 🟢 **Improvement**: >2% speedup (green)
- 🟡 **Warning**: >5% slowdown (yellow)
- 🔴 **Error**: >10% slowdown (red)

### Individual Benchmark Tools

```bash
# CPU microbenchmarks only (Criterion)
cargo bench

# Quick human-readable CPU check
cargo run --release --bin simple_benchmark

# Visual regression + performance (desktop + WASM)
python tests/visual/run_all_tests.py

# Desktop CLI rendering only
python tests/visual/run_tests.py

# WASM browser rendering only
python tests/visual/wasm/test_wasm.py
```

## CSV Format

### unified_benchmarks.csv

```csv
Timestamp, Platform, GitCommit, GitBranch, RustcVersion,
BenchmarkType, BenchmarkName, TestType,
Mean_ns, StdDev_ns, Throughput_ops_sec,
Width, Height, TotalIterations, RenderTime_ms, Throughput_Miter_sec
```

**Benchmark Types:**
- `cpu` - Criterion microbenchmark (Mean_ns, Throughput_ops_sec populated)
- `render` - GPU rendering test (Width, Height, RenderTime_ms populated)

**Test Types:**
- `` (empty) - CPU benchmark
- `desktop` - Desktop CLI export
- `wasm` - WASM browser export

## Example Usage

```bash
# Run full benchmark suite
python scripts/run_benchmarks.py

# Check for regressions (output is color-coded)
# Green = improvement, Yellow = >5% slower, Red = >10% slower

# View historical data
# Open benchmark_results/unified_benchmarks.csv in Excel/LibreOffice
# Plot performance over time by timestamp

# Compare specific commits manually
git checkout <commit-hash>
python scripts/run_benchmarks.py --quick
git checkout main
python scripts/run_benchmarks.py --quick
# Compare the two runs in unified_benchmarks.csv
```

## Notes

- **Quick mode** is recommended for development (faster, skip WASM)
- **Full mode** for comprehensive testing before release
- **CSV is append-only** - never delete historical data
- **Baseline is overwritten** - only stores last run
- Requires Pillow for PNG metadata extraction: `pip install Pillow`
