# Fractals For All
GPU-accelerated Fractal Flame Renderer

See our [demo in your browser](https://calibas.github.io/) (mobile not supported yet).

## Installation
Clone this reposity, [install rust](https://rust-lang.org/tools/install/) and then run:
```
cargo run
```
