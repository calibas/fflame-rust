# Experimental Features & Future Plans

This folder contains documentation for **future ideas**, **experimental designs**, and **exploratory work** that is not yet being actively developed.

## What Goes Here

- **Future feature proposals** - Ideas for features to implement later
- **Experimental designs** - Alternative architectures or approaches to explore
- **Research notes** - Background research on potential features
- **Proof-of-concept plans** - Designs for experiments to validate ideas
- **Performance optimization ideas** - Potential optimizations to investigate
- **Alternative approaches** - Different ways to solve problems (may never be implemented)

## Status Indicators

Use prefixes or sections to indicate status:
- `PROPOSAL-feature-name.md` - Feature proposal (not started)
- `EXPERIMENT-approach.md` - Experimental approach (may be tested)
- `RESEARCH-topic.md` - Background research

## File Organization

Organize by topic area:
```
experimental/
├── rendering/           # Rendering experiments
├── ui/                  # UI improvements
├── performance/         # Performance optimizations
├── features/            # New feature proposals
└── architecture/        # Architecture alternatives
```

Or keep flat with descriptive names.

## Promotion to Active Work

When an experimental idea becomes **active development**, move it to:
- `docs/projects/` - For work that's actively being implemented

## Examples of Experimental Topics

- Tiled high-resolution export
- Animation system with keyframes
- CUDA backend for NVIDIA acceleration
- Adaptive sampling strategies
- Denoising algorithms
- Real-time parameter morphing
- Layered compositing
- Alternative color modes
