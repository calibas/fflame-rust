# Accepted cross-platform divergences
#
# HAND-CURATED — not generated. Each line records a probe divergence
# that was investigated and deliberately not fixed, with the reason and
# the commit that carries the evidence. `variation_probe rank` reads
# this file and subtracts matching sites from its worklist, so the top
# of the list is always something nobody has looked at yet.
#
# An entry is not an exemption forever: it asserts the divergence is
# understood and consequence-acceptable AS MEASURED. If a variation's
# math changes, its entries deserve re-examination — the evidence
# commit is the anchor for that.
#
# Format, whitespace-separated:
#   <variation>  <dims>       comma-list: 2d, 3d
#   <inputs>     comma-list of probe input labels, or *
#   <reason...>  free text to end of line, citing the evidence commit
#
# The bar for adding a line: the mechanism is NAMED and MEASURED (not
# guessed), and the consequence is one of
#   - identical on both platforms (e.g. both reach bad-value recovery),
#   - a finite value difference too small to move a pixel,
#   - or the computation exceeds f32 argument resolution and ALL
#     implementations — including the f64 reference — produce mutually
#     different results, so no target class exists to guard toward.
#     (First case: trig of arguments past ~2^24, where adjacent f32s
#     differ by more than the whole period.)
# "Probably fine" does not clear the bar; that is what the worklist is
# for.

# Trig of unresolvable arguments: at |x*pi| beyond f32 resolution,
# measured sin/cos(1e20*pi): Metal fast (+0,+0) — point collapses to
# origin; NVIDIA (0, garbage) — point pins to the y-axis; IEEE/f64
# (-0.607, 0.794) — point scatters at radius |1+y|. Three
# implementations, three mutually-incompatible answers; a guard could
# only fake agreement with nothing. The tiny row is the reverse-
# direction flush: WINDOWS zeroes sin(3e-20) where Metal keeps it,
# ~1e-20 offset. (invpolar disposition)
invpolar     2d,3d  tiny,large,near_threshold,past_threshold,lopsided  trig past f32 argument resolution: no reference class exists (see header, third clause)

# Final REACHABLE sweep — every entry below was individually examined
# (glyphs decoded; npolar and waves2b micro-probed on the M2). Common
# thread: single-component finite<->zero or sign differences at exact
# special points, from three measured micro-mechanisms: (a) fast-math
# dropping the sign of finite*(+0), (b) NVIDIA flushing sin of tiny
# arguments to zero where Metal/IEEE keep them (Metal is the
# reference-correct side there), (c) trig past f32 argument resolution
