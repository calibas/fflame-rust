# The 3D camera: the record

Every camera now runs through one module, `src/camera/`; its reference
is [docs/main/CAMERA.md](../../main/CAMERA.md).

**3d-camera-system-apophysis.md** -- the original 4-angle camera after
Apophysis and JWildfire.

**free-camera-movement.md** -- fly mode and the free camera (stages 1-4),
and the record of where this camera deliberately differs from
JWildfire's (world-space `cam_pos`, 3D pan).

**camera-unification.md** -- one camera model for all seven cameras,
one gesture set, fly mode in every 3D view, touch's Alt and right
button (P0-P8, PR #130).
