# Archived ideas

Proposals and investigations from [docs/experimental/](../../experimental/)
that were since implemented, or overtaken by how the code went. Each
carries a banner saying which.

- **direct-color-variations.md** -- implemented: `direct_color` and the
  WritesColor/WritesRgb variations.
- **COLOR_TARGETING_APPROACHES.md** -- obsolete: the accumulator formula
  it builds on was removed.
- **PROPOSAL-spatial-path-correlation.md** and **PROPOSAL-path-caching.md**
  -- path tracking shipped, and Focused Rendering met the deep-zoom goal
  another way.
- **PROPOSAL-artistic-effects.md** -- depth of field shipped for 3D;
  motion blur did not, and is listed as an idea in the experimental
  README.

Other archived experiments sit with their topic:
[../escape-time/](../escape-time/) (perturbation theory, escape-time IFS,
the GPU reference-orbit experiment),
[../gpu-profiling/](../gpu-profiling/) (idle GPU usage) and
[../per-pixel-convergence/](../per-pixel-convergence/) (adaptive scale).
