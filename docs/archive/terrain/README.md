# The terrain: the record

The 3D height-field terrain shipped, for escape-time pictures and for
simulations; its reference is [docs/main/TERRAIN.md](../../main/TERRAIN.md).

**heightfield-3d.md** -- the plan and its dated record: sections to the
horizon, the walk, the render tiers, the path tracer, the denoiser, the
sky (T1-T4 and most of T5, PRs #128 and #131). HDRI environments, sun
shafts and terrain presets were deferred.

**terrain-height.md** -- the height map's quality (H1-H6): the Height
slider, curves and invert, the height lock at a zoom, the prefilter and
softness, the smooth surface, and an export's section cap fitted to the
card.

The shared materials model is in
[../projects/materials.md](../projects/materials.md); the camera's
record is in [../3d-camera/](../3d-camera/).
